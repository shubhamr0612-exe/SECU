# SECU Frontend

This is the React + Vite frontend for SECU.

For installation, environment configuration, development, and production build instructions, refer to the [main project README](../README.md).

## Development

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

The backend URL is configured through `VITE_BACKEND_URL` in the frontend environment file.
